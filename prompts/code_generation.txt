【关键断言文案】（必须按这个来，别自己编）

【可直接参考的完整示例】（照这个结构写）
```python
import allure
import pytest
from pages.login_page import LoginPage
from utils.config_reader import load_config
from utils.assertions import assert_contains

config = load_config()

@allure.feature("用户登录功能")
@allure.story("登录功能验证")
@pytest.mark.usefixtures("ensure_test_account")
@pytest.mark.parametrize("email,password,expected", [
    ("123456@gmail.com", "123456", "zoe"),
])
def test_login_success(page_context, email, password, expected):
    login_page = LoginPage(page_context)

    with allure.step("打开站点首页"):
        login_page.open(config["base_url"])

    with allure.step("进入登录页"):
        login_page.open_login_page()

    with allure.step("执行登录"):
        login_page.login(email, password)

    with allure.step("验证登录结果"):
        assert_contains(login_page.get_login_user(), expected)
```

【硬性约束】
1. 必须 POM：测试函数里只能调用页面对象的方法，
   禁止 page.locator(...) / page.click(...) / page.fill(...) 这类裸 API。
2. 测试函数签名必须是 def test_xxx(page_context, ...)，第一个参数是 page_context 固件。
3. 必须先 open(config["base_url"]) 打开站点首页，否则后续点击会超时。
4. 测试数据复用项目里已有的账号（123456@gmail.com / 123456，用户名 zoe），
   不要编造不存在的账号，否则登录必然失败。
5. 不要用 try/except 吞掉断言失败；不要用 time.sleep 等待。
6. 推荐加 @allure.feature / @allure.story 和 with allure.step(...) 步骤。

代码块外面**不要**写任何解释、说明、前言或总结文字。
